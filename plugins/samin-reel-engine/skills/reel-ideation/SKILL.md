# Reel ideation

Resolve `<plugin>` as the directory containing this plugin's `.codex-plugin/`. Run `python3 <plugin>/scripts/reel.py context` to find the configured project; pass `--project /absolute/checkout` **before** `context` when a project was supplied. Treat every `production/...`, `voice/...` and `runs/...` path as relative to that project. Shared references are linked below; load only this stage's instructions. Keep credentials and large working media out of the plugin cache.

Read [curated resource reels](../../references/curated-resource-reels.md), [templates](../../references/templates.md), [voice guide](../../references/voice-guide.md), and the Ideation section of [pipeline operations](../../references/pipeline-operations.md). Load only the selected story bank and relevant voice examples.

Default new ideas to one viewer outcome served by a small complementary resource stack. Carry the reference breakdown and ordered resource IDs into the idea. Compare outcome-first count hooks, select a distinct job for each item, and promise a giveaway containing the complete chosen stack. A batch is multiple outcomes, not a separate news reel for each item. Use another archetype when the user requests it or the evidence cannot support a useful stack; record that choice.

For each viable story, propose two or three genuinely different viewer payoffs/hooks. Select by usefulness, demonstrable mechanism, source strength, visual potential and voice fit. Do not choose a story solely for its star count or dramatic unsupported promise.

Define stable idea/story/reel IDs, archetype, chosen hook, short explanation, uppercase CTA keyword and the exact resource to deliver. Check Eden saves for an existing useful resource; record original-link, attributed-summary or original-worksheet reuse. Reject an angle if it cannot be explained honestly within the filming format.

Before handing to scripting, assign tentative visual jobs to the main beats: what will be shown, why it helps, and which evidence is already captured. A source-heavy story with no readable focal detail needs a different angle or capture plan. Save `ideation/ideas.json`, selected/rejected reasons and the giveaway promise. Do not call a draft accepted or published.
