# Voice calibration

The public plugin ships editing principles, not a creator’s private voice corpus. Before claiming a voice match, read at least three relevant scripts supplied by the current user. Keep samples and the generated voice profile local; they are ignored by Git.

## A practical starting shape

Use a clear hook → concrete input → mechanism → visible payoff → useful resource CTA. Short spoken paragraphs help the filming rhythm. A starting range is 98–195 words with 7–12 beats; this is a calibration range, not a quota or a guarantee of duration. Measure the current speaker’s delivery and prioritize the requested length.

Use concrete verbs and recognizable tools. Match the user’s vocabulary, sentence rhythm, transitions and preferred CTA using their actual examples. Do not invent first-person experiences, results or endorsements to imitate a style. Verify facts independently of the voice samples.

## Build and use the profile

Run `python3 tools/hold-your-voice/hold_voice.py profile --help` for the current local interface, then build a profile from the user-provided samples. Run `scan` on a clean draft and review its flags against the actual examples. A scan is a style aid, not proof of voice fidelity. Change the profile only from accepted examples or explicit feedback.

## Filming handoff

Save clean spoken copy separately from editor notes. Each beat needs a visual job, source request, spoken anchor, readable focal detail and intended viewer takeaway. Build the promised giveaway before finalizing the CTA. Estimated timing becomes measured timing only after recording.
